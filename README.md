# 🛡️ Site Compliance Shield (Защита сайтов от штрафов)

> **Antigravity / Claude Code / Cursor AI Skill**: Комплексный инструмент технического и юридического аудита веб-проектов и вайбкодинга на соответствие законодательству РФ (152-ФЗ, РКН, ФАС, ЗоЗПП, ст. 13.11 КоАП РФ). Защита от штрафов до 20 000 000 ₽.

## 📌 О проекте

В 2026 году тренд **«вайбкодинга» (vibe coding)** — создания сайтов и приложений исключительно с помощью нейросетей (Cursor, Claude Code, v0, Bolt) без глубоких технических знаний — столкнулся с резким ужесточением законодательства РФ. 

За утечки баз данных введены оборотные штрафы **от 3 до 20+ млн рублей**, а сбор контактов на зарубежных серверах (Vercel, Supabase, Firebase, AWS) квалифицируется как нарушение первичной локализации данных в РФ (штрафы **до 6–18 млн рублей**).

Этот скилл обучает ИИ-агента проводить детальный аудит любого репозитория или страницы перед релизом.

## 📋 Чек-лист из 20 задач (5 блоков)

### 1. Персональные данные и Cookies (152-ФЗ)
1. **Политика конфиденциальности:** Доступна с любой страницы в футере в 1 клик с реквизитами оператора.
2. **Раздельные согласия:** Отдельный чекбокс на обработку ПДн и отдельный чекбокс на рекламные рассылки.
3. **Неактивные чекбоксы:** Чекбоксы по умолчанию пустые (без галочки по умолчанию).
4. **Баннер Cookies:** Уведомление о сборе cookies и системах веб-аналитики (Яндекс.Метрика).
5. **Локализация инфраструктуры:** Первичный сбор данных производится строго на серверах в РФ.

### 2. Реклама и маркировка (ФЗ «О рекламе», ЕРИР)
6. **Токенизация рекламы:** Плашка «Реклама», указание рекламодателя и токен erid.
7. **Партнёрские ссылки:** Проверка реферальных и промокодных программ.
8. **Запрет неподтверждённых степеней:** Устранение фраз «№1», «лучший», «100% гарантия».
9. **Дисклеймеры:** Наличие обязательных предупреждений для регулируемых сфер.

### 3. Электронная коммерция (ЗоЗПП)
10. **Публичная оферта:** Полноценный документ с порядком оплаты, доставки и расторжения.
11. **Синхронизация цен:** Цены в каталоге и в корзине строго совпадают.
12. **Правила возврата:** Прозрачный регламент возврата средств по ст. 26.1 ЗоЗПП.

### 4. Авторские права и контент
13. **Лицензии:** Проверка коммерческих лицензий на шрифты и медиа.
14. **Возрастная маркировка:** Наличие плашек 16+ / 18+.
15. **Специальные статусы:** Корректное указание статусов иноагентов.

### 5. Безопасность и секреты вайбкодинга
16. **Скан репозитория на утечки секретов:** Запрет хардкода API-ключей и токенов в клиентском JS.
17. **Изоляция бэкенда:** Вызовы внешних сервисов только через закрытые переменные окружения .env.
18. **SSL / HTTPS:** Отсутствие mixed content.
19. **Валидация форм:** Защита от спама и SQL-инъекций.
20. **Доступность (A11y):** Семантика, контрастность, валидность юридических ссылок.

## 💻 Установка скилла

### Для Google Antigravity:
Склонируйте репозиторий в папку пользовательских скиллов:
```bash
git clone https://github.com/hurters/site-compliance-shield.git %USERPROFILE%/.gemini/config/skills/site-compliance-shield
```

### Использование:
В чате с ассистентом вызовите:
```text
/site-compliance-shield проведи аудит моего проекта
```
